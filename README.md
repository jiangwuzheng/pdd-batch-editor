## 4 步流程（每商品必做，详见 SKILL.md 与交接卡）

1. **改属性**：是否防水→**不防水**；连续照明时间→**1小时**
2. **SKU 全删重建 26 个**（按参照 699950114171）：21个10瓦 + 3个8瓦 + 2个定制；规格名**必须带空格**（如 `10瓦 白黄橙冰 无极调光CD1`）；定制规格必须先勾"部分库存定制"再点"添加定制规格"（出现**橙色定制标签**）；价格三档 10瓦139/149、8瓦128/129、定制169/179；下架款库存清空
3. **详情页 25 张图**：图片空间 `全部文件 > 手电筒造影灯罩组合 > 详情页2 > ai批量上传`，按文件名顺序（1,2,3 = FAQ/售后/色卡 排最前，4~25 = cd1--详情页_01~_22）；用 `add_by_name_any.py` 看名字挨个点（不靠搜索）
4. **存草稿 + 提交**：保存草稿 → 提交（real_click 有效，弹窗自动点确定）→ 验证 URL 跳 `goods_add/success`

## 使用方式（给 AI 的指令模板）

```bash
# 1. 先扫描页面拿坐标（web-recon 技能，操作前必扫）
python scan_page.py --match goods_add --out <输出目录>

# 2. 单商品全流程（SKU部分）
python run_full.py <gid>
python fix_attr.py            # 属性（或 run_full 内含）

# 3. 详情页25图（用户认可的"看名字挨个点"方案）
python clear_canvas2.py       # 清空画布
python add_by_name_any.py     # 25图按名添加（幂等，可重复跑）
python verify_decor755.py     # 校验 25/25
python save_decor2.py         # 保存装修

# 4. 存草稿+提交
python save_draft3.py
python do_submit_final.py
```
